## 手动复验后台触发

1. `dotnet run --project tools/InputProbe -c Release` 启动本仓库的输入验证窗口。
2. 在 FocusTone 创建绑定到 `FocusTone.InputProbe.exe` 的 F8 规则。
3. 最小化 FocusTone，聚焦验证窗口并按 F8；声音应播放，验证窗口也应收到 F8。
4. 聚焦其他窗口按 F8，应无新的规则触发。
5. 从托盘或再次启动 EXE 恢复主界面，检查底部触发状态。
6. 暂停全部快捷键再次测试，恢复开关后再次测试。
